
🎵 Web Music Player (Spotify Clone)
A fully functional, responsive web-based music player built with JavaScript, HTML, and CSS. This project dynamically fetches audio files and album metadata from the server, mimicking the core functionality of popular music streaming apps.
👉 Live demo: https://music-player.infinityfree.me/
✨ Features
Dynamic Album Fetching: Automatically reads folders on the server to generate clickable album cards using album-specific info.json and cover images.

Dynamic Playlists: Clicking an album fetches and lists all .mp3 files contained within that specific folder.

Full Audio Controls: Play, pause, next track, and previous track functionality.

Interactive Seekbar: Real-time progress tracking and the ability to click anywhere on the timeline to scrub through the song.

Volume Management: Range slider for volume control and a click-to-mute/unmute toggle.

Synchronized UI: Sidebar playlist icons and the main playbar automatically stay in perfect sync to reflect the currently playing track.

Responsive Design: Hamburger menu and slide-out sidebar for a seamless mobile browsing experience.

🛠️ Tech Stack
Frontend: HTML5, CSS3

Logic: JavaScript

Backend/Server: Apache Server (Relies on Apache directory listing to parse folders)
